# Al Ritrovo, sito della pizzeria

Sito vetrina di **Al Ritrovo**, Via Milano 51, 20067 Paullo (MI). Pagina singola in HTML, CSS e JavaScript, senza dipendenze: si apre aprendo `index.html`.

## Struttura
- `index.html`: tutta la pagina (testi, stili, menu, orari)
- `img/`: foto e logo. Per usare le foto vere del locale, sostituisci i file mantenendo lo stesso nome (`hero.jpg`, `padellino.jpg`, `sfincione.jpg`, `arancine.jpg`, `cannoli.jpg`, `specialita.jpg`, `aperitivo.jpg`, `pizzaiolo.jpg`, `poster.jpg`, `logo.png`).

## Cosa modificare
- **Orari:** cerca `var H =` nello script (orari usati per "Aperto ora") e la lista `id="hours"` (orari mostrati).
- **Menu e prezzi:** cerca `var PIZZE`, `var CALZONI`, `var AGGIUNTE` nello script. Ogni voce e' `[nome, prezzo, ingredienti]`.
- **Link Deliveroo:** cerca `deliveroo.it` (due punti).
- **Telefono e WhatsApp:** cerca `35950189` e `3714292170`.
